# Branding Intelligence — HazPost

## Objetivo

HazPost debe generar percepción visual premium y coherencia real de marca.

El objetivo NO es solo detectar colores.

El objetivo es:

- entender identidad visual,
- mantener consistencia,
- generar percepción premium,
- evitar branding mediocre,
- aumentar confianza comercial.

---

## Principio crítico

Branding incorrecto destruye percepción premium.

Es mejor NO sugerir color que sugerir branding mediocre o incorrecto.

---

## Prioridad visual oficial

Orden oficial de confianza:

1. Uploaded logo
2. Referencias visuales reales
3. Website branding
4. IA contextual
5. Defaults neutros

---

## Reglas críticas

Nunca:

- usar colores bootstrap/UI random,
- asumir branding por screenshots aislados,
- asumir color dominante sin confianza alta,
- usar checkerboards/transparencias como color real,
- usar branding HazPost como branding del negocio,
- persistir palettes mediocres automáticamente.

---

## Branding Intelligence Agent

Responsable de:

- logo analysis,
- palette extraction,
- color confidence,
- visual consistency,
- visual references,
- branding coherence,
- premium perception.

NO debe:

- inventar branding,
- sugerir colores sin confianza alta,
- sobrescribir branding real con IA débil,
- mezclar branding entre negocios.

---

## Color governance

La extracción de color debe:

- priorizar logos reales,
- detectar colores dominantes reales,
- ignorar backgrounds neutros,
- ignorar checkerboards,
- ignorar colores accidentales,
- validar saturación útil,
- validar contraste,
- validar coherencia visual.

---

## Confidence system

El sistema debe usar confidence scoring.

Si la confianza es baja:

- NO asumir branding,
- NO persistir colores mediocres,
- NO sobrescribir colores existentes confiables,
- usar defaults neutros seguros.

---

## Website analysis integration

Website analysis puede aportar señales visuales, pero NO debe ganar automáticamente sobre logo o referencias visuales reales.

Website colors son heurísticos.

AI-generated HEX es fallback, no verdad absoluta.

---

## Multi-business isolation

Nunca mezclar branding entre negocios.

Nunca reutilizar entre marcas:

- palettes,
- logos,
- colores,
- referencias visuales,
- branding memory.

---

## UX premium

El usuario debe sentir:

- coherencia,
- identidad visual real,
- percepción premium,
- consistencia,
- calidad visual profesional.

---

## Objetivo final

HazPost debe sentirse como:

- una agencia premium,
- un director creativo inteligente,
- y una plataforma que realmente entiende marcas reales.

---

## Runtime ownership

Branding Intelligence NO es source-of-truth único.

Debe respetar:

- onboarding,
- business profile,
- uploads reales,
- overrides manuales del usuario,
- persistencia DB,
- runtime hydration.

La decisión final visual siempre pertenece al negocio.

---

## AI safety rules

La IA visual nunca debe:

- copiar branding de otra marca,
- replicar identidades famosas,
- reutilizar palettes entre clientes,
- generar branding confuso,
- producir combinaciones ilegibles,
- romper accesibilidad básica.

---

## Future evolution

Branding Intelligence evolucionará hacia:

- visual DNA memory,
- style consistency scoring,
- creative direction AI,
- cross-post visual coherence,
- industry-aware branding,
- trend-aware palettes,
- premium aesthetic scoring,
- brand evolution suggestions.
