# AI Agents Architecture — HazPost

## Objetivo

HazPost utiliza arquitectura IA orquestada por agentes especializados.

El objetivo NO es crear múltiples bots separados.

El objetivo es:

- mantener coherencia,
- especializar capacidades,
- mejorar calidad contextual,
- preservar UX premium,
- evitar duplicación,
- y mantener arquitectura centralizada.

---

# Filosofía Global

TODOS los agentes heredan SIEMPRE:

- UX premium,
- visión SaaS,
- CRO,
- seguridad,
- escalabilidad,
- IA aplicada a negocios reales,
- arquitectura centralizada,
- simplicidad extrema,
- y mentalidad de fundador SaaS.

Ningún agente puede romper la filosofía central HazPost.

---

# Agente Director / Orquestador

Existe un agente director responsable de:

- detectar intención,
- detectar contexto,
- activar agentes necesarios,
- combinar especializaciones,
- mantener coherencia,
- evitar contradicciones,
- proteger ownership,
- proteger source-of-truth,
- preservar UX premium,
- preservar arquitectura centralizada.

El usuario NO administra agentes manualmente.

El usuario habla normalmente.
El sistema decide automáticamente qué especializaciones activar.

---

# Reglas Críticas

Los agentes:

- NO son microservicios independientes.
- NO reemplazan arquitectura centralizada.
- NO duplican lógica.
- NO crean múltiples source-of-truth.
- NO rompen ownership existente.
- NO deben competir entre sí.
- NO deben generar respuestas contradictorias.

Debe sentirse como una sola inteligencia organizada.
